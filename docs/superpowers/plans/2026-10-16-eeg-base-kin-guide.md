# EEG-base model with a training-only kinematic guide: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An EEG-only model (input: EEG band power; output: EMG envelope of 5 muscles) whose training is guided a little by a frozen kinematic teacher that is absent at test time.

**Architecture:** New package `v3/` on a new branch. The student is the v2 `EEGStream` unchanged (kept under the attribute name `eeg`, so its state keys equal v2's `eeg.*`). The teacher is the v2 `KinStream` (attribute `kin`) loaded from the user's v2 checkpoints and frozen. Small guide heads and three guide losses (`align`, `distill`, `kin_aux`) live only in the training code. Checkpoints that are used for evaluation hold the student only.

**Tech Stack:** Python 3, PyTorch, NumPy, pandas, SciPy (`scipy.stats.wilcoxon`), pytest; Jupyter notebook generated by a script, like `tools/build_main_v2_notebook.py`.

**Spec:** `docs/superpowers/specs/2026-10-16-eeg-base-kin-guide-design.md`

## Global Constraints

- Branch: `KG-GT-v3-eeg-guided`, cut from the current `KG-GT-v2` HEAD. Never push.
- Commits: `git add` explicit paths only; **no `Co-Authored-By` or any Claude attribution line** (user rule overrides the harness default); never add `.superpowers/`, `main_v2.ipynb`, `v2-report/*` or any file the user has modified but not committed.
- Never run real training or evaluation; never load the user's checkpoints; never create, modify or delete anything under `data/`, `outputs/`, `results/` (reading saved CSVs in tests is not allowed either: tests use temporary files). Allowed: unit tests, CPU smoke tests with random weights, GPU memory/time smoke on random data if the GPU is free.
- Python: `env/Scripts/python.exe`. Test command: `env/Scripts/python.exe -m pytest tests -q`.
- Do not change any file under `v2/`. Import from it.
- At test time the model receives EEG only: no kinematics, no history, no teacher.
- Model selection and early stopping use the validation loss of E only (v2 `StreamLoss` on E), never a guide term.
- Guide strength grid: `guide.scale` in `[0.0, 0.05, 0.1, 0.3]`; base weights `w_align = 1.0`, `w_distill = 0.5`, `w_aux = 0.5`; default terms `["align", "distill"]`; default schedule `"fade"`.
- Success numbers used by the report code: saved E mean r 0.645; "close to timing baseline" = mean r >= (phase mean r - 0.05); stretch = above phase mean r.
- Code style follows `v2/`: short docstrings that state the rule, no hashes in file names, outputs under `outputs/checkpoints_v3/`, `results/v3/`.

## Review Focus

1. A participant has no v2 K checkpoint: the notebook prints a skip line for that participant and continues (test in Task 2 and Task 8).
2. A v2 checkpoint was trained with another model config (causal, other `d_model`): the teacher load fails with a message naming the path and the differing key, never runs with mismatched weights (Task 2).
3. Training is interrupted during the fade and resumed: the guide weight continues from the saved epoch, not from the start (Task 5).
4. `guide.scale = 0.0`: the run is exactly the E-only control, the teacher is not even run, and the loss equals the v2 E loss (Tasks 4 and 5).
5. Mixed precision on: the guided loss stays finite (cosine and Huber computed in float32) (Task 4).

### Task 4: Guide heads, guide losses and the schedule

**Files:**
- Create: `v3/guide.py`
- Test: `tests/test_v3_guide.py`

**Interfaces:**
- Consumes: `v2.losses.StreamLoss`, `v2.losses.huber`; student output dict (Task 1); teacher output dict (Task 2); a batch dict from `v2.data.TokenWindows` (`"kin"`, `"hist"`, `"eeg"`, `"target"`, `"hold_id"`).
- Produces:
  - `v3.guide.GuideHeads(nn.Module)`: `align: nn.Linear(d, d)`, `aux: nn.Linear(d, len(aux_columns))`; built by `build_heads(cfg) -> GuideHeads`.
  - `v3.guide.align_loss(student_tok, teacher_tok, proj) -> Tensor` = mean over (B,T) of `1 - cosine(proj(s), t.detach())`, computed in float32.
  - `v3.guide.distill_loss(e, k, delta) -> Tensor` = `huber(e, k.detach(), delta)`.
  - `v3.guide.aux_loss(student_tok, kin_z, columns, head) -> Tensor` = Huber (delta from config) between `head(s)` and `kin_z[..., columns]`.
  - `v3.guide.guide_weight(epoch: int, cfg) -> float`: `scale * g(epoch)`; `g` per schedule: `"off"` → 0; `"constant"` → 1; `"fade"` → `(epoch + 1) / warmup_epochs` while `epoch < warmup_epochs`, then 1 while `epoch < hold_until`, then `1 - (epoch - hold_until) / (off_at - hold_until)` while `epoch < off_at`, then 0. `epoch` counts from 0.
  - `v3.guide.guided_loss(student_out, teacher_out, batch, heads, crit, cfg, epoch) -> tuple[Tensor, dict]`: `L = crit(E, target, hold_id) + w * (w_align * align + w_distill * distill + w_aux * aux)` over the enabled `terms`; `align` and `kin_aux` read the student tokens `"fin"` when `guide.align_at == "final"` and `"mid"` when it is `"mid"`, and `align` pairs them with the teacher's token of the same name; the dict holds floats `"emg"`, `"align"`, `"distill"`, `"aux"`, `"w"` (absent terms are 0.0). When `w == 0.0` the guide terms are not computed and `teacher_out` may be `None`.
  - `v3.guide.guide_grad_share(params, l_emg, l_guide) -> float` = `|g_guide| / (|g_emg| + |g_guide|)` from `torch.autograd.grad(..., retain_graph=True, allow_unused=True)`; 0.0 when `l_guide` has no graph.

- [ ] **Step 1: Write the failing tests:**
  - `test_schedule_fade_values`: with `scale 1.0`, `warmup_epochs 5`, `hold_until 40`, `off_at 60`: `guide_weight` at epochs 0, 4, 39, 40, 50, 59, 60, 149 is `0.2, 1.0, 1.0, 1.0, 0.5, 0.05, 0.0, 0.0` (approx 1e-9).
  - `test_schedule_constant_and_off_and_scale`: constant with scale 0.3 → 0.3 at epoch 100; off → 0.0 everywhere.
  - `test_align_zero_when_identical`: `proj` set to identity and `s == t` → `align_loss` < 1e-6.
  - `test_no_gradient_into_teacher_tokens`: teacher tensors created with `requires_grad=True` get `grad is None` after `guided_loss(...)[0].backward()`.
  - `test_scale_zero_is_the_v2_e_loss`: with `scale 0.0` and `teacher_out=None`, the total equals `StreamLoss(**cfg["loss"])(E, target, hold_id)[0]` exactly and the dict's guide entries are 0.0.
  - `test_align_at_mid_uses_mid_tokens`: with `align_at "mid"` the align loss changes when `student_out["mid"]` changes and not when `"fin"` changes.
  - `test_terms_switch`: with `terms == ["distill"]`, `align` is 0.0 and the align projection gets no gradient.
  - `test_finite_under_autocast`: on CPU with `torch.autocast("cpu", dtype=torch.bfloat16)`, the total is finite.
  - `test_grad_share_bounds`: result lies in [0, 1]; equals 0.0 when the guide loss is a constant.

### Task 5: Guided training loop with E-only selection

**Files:**
- Create: `v3/train.py`
- Test: `tests/test_v3_train.py`

**Interfaces:**
- Consumes: Tasks 1, 2, 4; `v2.train._check_config(path, ck, cfg, log)` for the resume config check; `v2.data.TokenWindows`.
- Produces:
  - `v3.train.evaluate_e_loss(student, loader, crit, device, use_amp) -> float`: mean v2 `StreamLoss` of E on the loader, no guide terms.
  - `v3.train.fit_guided(student, teacher, heads, train_ds, val_ds, cfg, device, ckpt_dir, resume=True, log=print) -> dict` (history). `teacher` may be `None` only when `cfg["guide"]["scale"] == 0.0`, otherwise `ValueError`.
  - Files in `ckpt_dir`: `best.pt` = `{"state": student.state_dict(), "history", "config", "epoch", "training_complete"}`; `last.pt` = the same plus `"heads_state"`, `"optimizer_state"`, `"scheduler_state"`, `"scaler_state"`, `"best"`, `"bad"`, `"recent"`; `history.json`; `metrics.csv`.
  - `v3.train.load_student(student, ckpt_dir, device) -> dict` (loads `best.pt["state"]`, returns history).
  - History keys: `"train_emg"`, `"train_align"`, `"train_distill"`, `"train_aux"`, `"w"`, `"grad_share"`, `"val_e"`, `"best_epoch"`, `"epochs_run"`, `"total_time_s"`.

Rules (from the spec): one AdamW over `student` + `heads` (lr, weight decay as v2); warm-up + cosine `LambdaLR` as v2's `lr_at`; `GradScaler`; clip 1.0 over student + heads; skip the step if the norm is not finite. Teacher forward only when `guide_weight(epoch, cfg) > 0`. `grad_share` is computed on the first batch of each epoch with `guide_grad_share`. Early stopping on the 3-epoch smoothed `val_e` with `patience` epochs, but never before `min_epochs = off_at` when the schedule is `"fade"` (else 0). The best state is the student's state at the best smoothed `val_e`. Resume: a matching `last.pt` restores everything including the epoch, so `guide_weight` continues from the saved epoch; a completed run is skipped and loads `best.pt`.
